# Frontend - Portfolio Website

Next.js 前端应用，展示个人作品集。

## 开发

```bash
# 安装依赖
npm install

# 运行开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm start
```

## 组件

### 布局组件
- `Header` - 导航头部
- `Footer` - 页脚

### 页面组件
- `Hero` - 首页横幅
- `ProjectCard` - 项目卡片
- `ProjectTabs` - 项目分类标签
- `SkillsGrid` - 技能网格
- `ContactForm` - 联系表单
